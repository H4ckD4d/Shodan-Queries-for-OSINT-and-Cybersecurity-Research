# Security and Responsible Use

> **Project owner and original creator: Chris Cruz | h4ckd4d**

This repository is intended for defensive security, education, OSINT research, External Attack Surface Management, and explicitly authorized assessment.

## Rules of use

Use query patterns only for:

- assets you own or administer;
- environments for which you have explicit authorization;
- defensive asset inventory and exposure management;
- documentation and training using reserved or fictional examples.

Publicly indexed data is not permission to access, authenticate to, modify, exploit, disrupt, or test a third-party system.

## Repository safety

Do not publish:

- credentials, API keys, tokens, or private keys;
- personal or victim data;
- sensitive third-party asset details;
- query collections designed to locate vulnerable third-party targets;
- exploitation or authentication workflows.

## Reporting repository problems

Use GitHub Issues for unsafe examples, outdated vendor syntax, broken references, incorrect semantics, or documentation problems. Keep reports limited to the minimum information needed to reproduce the documentation issue safely.
